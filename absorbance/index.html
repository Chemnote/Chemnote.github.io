흡광도 검량선 연습

KMnO₄ 표준용액 제조부터 검량선 작성, 미지시료의 표준용액(1,000 ppm) 대비 희석배수 계산까지 실기 과정을 연습하는 도구입니다. 노란 칸만 입력하면 됩니다.

모드 선택

표준용액 흡광도

미지시료

표준용액 흡광도 3개와 미지시료 흡광도를 모두 입력해 주세요.

정상/오차 모드는 버튼을 누를 때마다 임의의 실험 데이터를 새로 생성합니다. 실제 실기시험처럼 검량선을 읽고 계산 과정을 연습해 보세요.

요구사항 핵심

  1. 가
    Calibration — 파장 540 nm 확인, 순수용액으로 100%T 또는 0.0000 A 확인
  2. 나
    표준용액 — KMnO₄ 1000 ppm으로 blank, 5, 10, 15 ppm을 100 mL 부피 플라스크로 제조 후 측정

    표준용액 흡광도 측정은 원칙적으로 1회만 허용

  3. 다
    미지시료 — 농도 20~80 ppm. 흡광도가 5~15 ppm 범위에 들도록 희석해 측정 (희석·측정 횟수 제한 없음)

    범위를 벗어나면 반드시 희석작업 재수행

  4. 라
    분석그래프
    • 가로축 농도, 세로축 흡광도 — 측정값을 모두 포함하도록 눈금 단위(scale) 기록
    • 표준 점은 점(·)으로 찍고 (농도, 흡광도) 양식으로 기록
    • 자를 이용해 모든 점과 근접한 일직선 검량선
    • 미지시료 흡광도: 세로축에 화살표(→), 값은 그래프용지 좌측에 기록
    • 가로축과 평행한 점선 → 검량선과의 접점 → 세로축과 평행한 점선 → 가로축 하단에 화살표(↑)
    • 농도는 소수점 둘째자리까지 (0이어도 두 자리: 5.25, 6.30)
  5. 마
    희석배수 — 미지시료가 표준용액(1000 ppm)으로부터 몇 배 희석되었는지 계산

    1,000 ppm / 미지시료 원액 농도
