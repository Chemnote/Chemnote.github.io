# Chemnote

**화공 수험생을 위한 계산 도구 모음** — 설치 없이 브라우저에서 바로 사용하세요.
**Free browser-based chemical engineering tools** for Korean certification exam prep. No install needed.

👉 **https://chemnote.github.io**

| 도구 (Tool) | 설명 | Description |
|---|---|---|
| [단증류 시뮬레이터](https://chemnote.github.io/distillation/) | 화공기사 실험: 밀도→조성 보간, 물질수지, Rayleigh 식 I값 판독 | Simple (batch) distillation lab data: density→composition, mass balance, Rayleigh equation |
| [연소 공기량 계산기](https://chemnote.github.io/combustion/) | 대기환경기사 연소공학: 공기량, 연소가스량, 배출가스 조성 | Combustion air & flue gas calculator |
| [흡광도 검량선 연습](https://chemnote.github.io/absorbance/) | 화학분석기능사 실기: 검량선 작성과 시료 농도 계산 | Absorbance calibration curve practice |
| [습공기 상태 계산기](https://chemnote.github.io/psychrometric/) | 두 상태값으로 습공기 상태량 계산, 습공기선도 표시 | Psychrometric (moist air) state calculator with chart |

계산 결과는 학습용 참고 자료입니다. / Results are for study reference only.
