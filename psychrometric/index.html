습공기 상태 계산기

상태값 두 개를 고르면 나머지를 모두 계산하고 습공기선도 위에 표시합니다.

    습도 · 엔탈피

    절대습도 ↔ 수증기분압

    x=0.62198PwP−PwPw=xP0.62198+x

    상대습도

    φ=100×PwPws(t)

    φ는 %로 나타냅니다.

    엔탈피

    h=Cpat+(Cpvt+r0)x
    =1005t+(1846t+2501000)x

    단위는 J/kg′이고, 입력칸에서는 kJ/kg′으로 씁니다.

    건구·습구온도 → 절대습도

    x=(r0+Cpvt′−hc)xs′−Cpa(t−t′)Cpvt+r0−hc
    hc={Cwt′  (t′ ≥ 0, 물)−Lf+Cit′  (t′ < 0, 얼음)

    xs′은 습구온도 t′에서의 포화 절대습도, 즉 0.62198·Pws(t′) / (P − Pws(t′))입니다.

    입력 조합별 풀이

    건구온도 t와 절대습도 x를 먼저 구하고, 나머지는 위 식으로 계산합니다

    입력t, x 구하는 방법
    건구 + 습구위의 “건구·습구온도 → 절대습도” 식으로 x
    건구 + 절대습도바로 사용
    건구 + 상대습도Pw=φPws(t)/100 → x
    건구 + 엔탈피x=h−CpatCpvt+r0
    절대습도 + 엔탈피t=h−r0xCpa+Cpvx
    절대습도 + 상대습도Pws(t)=100Pw/φ, 이 압력을 노점 식에 넣어 t
    습구 + 절대습도“건구·습구 → 절대습도” 식을 t에 대해 정리해 바로 계산
    습구 + 상대습도
    습구 + 엔탈피
    상대습도 + 엔탈피    		t를 뉴턴법으로 반복 계산 (아래)
    노점 + 건구·습구·
    상대습도·엔탈피    		노점 식을 거꾸로 풀어 Pw를 구하고 → x. 그다음은 위의 “절대습도 + ○○” 조합과 같습니다.
    노점 + 절대습도둘 다 수분량이라 같은 정보입니다. 함께 고를 수 없습니다.

    뉴턴법 반복 계산습구온도를 구할 때도 같은 방법

    tn+1=tn−F(tn)F′(tn)F′(t)≈F(t+0.1)−F(t)0.1

    |tn+1 − tn| ≤ 0.02 ℃가 되면 멈춥니다(습구 + 엔탈피 조합은 0.001 ℃). 최대 100회 반복합니다. 습구온도는 F(t′) = h(t′, xs′) − h − (xs′ − x)·hc(t′) = 0을 풀어 구합니다.
